# Mission: RAG Production — De la teoría a la implementación

## Why
Construir sistemas RAG (Retrieval-Augmented Generation) en producción que funcionen de verdad. No demos de 30 minutos, sino sistemas que soporten tráfico real, mantengan calidad con el tiempo, y puedan evaluarse objetivamente. El repositorio `hands-on-rag` del libro "Hands-on RAG for Production" será nuestro laboratorio.

## Success looks like
- Poder explicar y justificar cada decisión de arquitectura RAG (chunking, retrieval, reranking, evaluación)
- Implementar un pipeline RAG completo usando el repositorio como referencia
- Evaluar la calidad de un sistema RAG con métricas concretas (faithfulness, context precision, recall)
- Distinguir cuándo usar RAG vs long-context vs fine-tuning
- Diseñar un sistema Agentic RAG con herramientas de retrievial dinámico

## Constraints
- Foco en producción, no en prototipos
- Inglés para código y documentación, español para explicaciones
- Usar el repositorio hands-on-rag como fuente principal de código

## Out of scope
- Fine-tuning de modelos desde cero
- Construir un LLM propio
- Infraestructura de GPU/infraestructura on-premise
