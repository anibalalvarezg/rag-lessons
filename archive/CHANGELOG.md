# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-24

### Added
- 9 complete lessons covering RAG in production
- Pillar 1 — Fundamentals: What is RAG, pipeline basics
- Pillar 2 — Ingestion: Chunking strategies, embeddings, vector stores, hybrid retrieval, reranking
- Pillar 3 — Agentic & GraphRAG: Agentic RAG, multimodal RAG, Microsoft GraphRAG
- Pillar 4 — RAGOps: Guardrails, hallucination detection, evaluation & metrics
- Interactive quizzes per lesson
- Practice exercises per lesson
- RAG glossary with 19 key terms
- Course homepage with editorial layout
- SEO meta tags, Open Graph, structured data (JSON-LD)
- Dark mode support via `prefers-color-scheme`
- Responsive design (mobile-first)
- Print styles
- `prefers-reduced-motion` support
